# Career Arbor 品牌强化与结果分层防溢出设计规格

- 日期：2026-08-10
- 状态：**Implemented / Validated**（实现与验证基线 `langgraph@d423a4b`）
- 选定方向：方案 A——枝条生长式品牌动效
- 影响范围：仅前端展示、样式、翻译与对应回归测试

## 1. 背景与目标

当前界面存在三个可见问题：

1. 页面左上角的“枝涯 / Career Arbor”字号偏小、点击面积不足，也缺少能强化品牌记忆的反馈。
2. 主页的“枝涯 Career Arbor · 循枝见路，向远而生 / Career Arbor · Follow the branches, find your path.”仍按普通 eyebrow 小字呈现，无法承担网站名称的视觉识别作用。
3. P3 岗位结果表的英文分层文案过长，可能越过固定的分层列并侵入岗位名列。

本次改动的目标是：在不改变现有暖色、纸感、编辑式视觉体系的前提下，提高品牌名称的可见性和可点击性；用与“Career Arbor”主题一致的克制动效增强记忆；让中英文岗位分层在所有目标宽度下保持边界稳定。

## 2. 非目标与边界

- 不重做导航、主页或结果页的信息架构。
- 不新增图片、位图、外部字体或第三方动画依赖。
- 不改变品牌主页链接的路由行为、认证逻辑或可访问名称。
- 不改变后端枚举、API 字段、数据库值或持久化契约。
- 不改变中文分层含义。
- 不移动受版本控制的源码、测试源码、文档、配置或数据。
- 不以“未跟踪”或“被 Git 忽略”作为判定文件冗余的依据。

## 3. 已评估方案

### 方案 A：枝条生长式品牌动效（采用）

放大文字品牌；在悬停和键盘聚焦时，让一条暖橙色细枝从左向右延展，并在末端呈现小叶节点。动效只使用 `transform` 与 `opacity`，不改变布局。

优点：与 Career Arbor 语义直接相关，能形成独有的品牌动作，同时保持现有设计的克制感。实现范围小，可完整覆盖键盘与低动态模式。

### 方案 B：发光胶囊

把品牌放入带阴影或发光的圆角容器。视觉更强，但容易呈现为通用 SaaS 徽章，并会增加导航栏的视觉重量。

### 方案 C：新增树形 SVG 标志

在文字旁增加独立图形标志。品牌识别最强，但需要新增图形资产、更多中英文组合验证与窄屏适配，不符合本次小范围修复的比例原则。

## 4. 详细设计

### 4.1 全局品牌主页链接

涉及组件：`frontend/src/v2/BrandHomeLink.tsx`

涉及样式：`frontend/src/v2/theme.css`

设计要求：

- 保持现有链接元素、`to="/"`、intro 标记和中英文切换逻辑不变。
- 将品牌文字调整为响应式字号，目标范围约为 `1.45rem–1.8rem`；窄屏以不碰撞菜单按钮和语言按钮为上限。
- 链接使用 `inline-flex` 垂直居中，并提供至少 `44px × 44px` 的有效命中区域。
- 保留桌面侧栏品牌文字与会话文字的左侧栅格关系；放大不得破坏既有对齐。
- 用装饰伪元素绘制枝线与叶节点：空 `content`、`pointer-events: none`，不得影响可访问名称或点击。
- `hover` 和 `focus-visible` 使用统一的约 `220ms` ease-out 动效：文字转为强调色，枝线伸展，叶节点显现；`active` 只允许轻微 `transform`，不触发布局位移。
- `focus-visible` 必须保留独立、清晰的轮廓，不能只依赖颜色或装饰枝线表达焦点。
- `prefers-reduced-motion: reduce` 下关闭位移、缩放和非必要过渡；焦点轮廓与静态枝线立即可见。

### 4.2 主页品牌锁定区

涉及组件：`frontend/src/v2/HomePage.tsx`

涉及样式：`frontend/src/v2/marketing.css`

涉及翻译：`frontend/src/i18n/en.ts`

现有共享 `.mk-eyebrow` 不全局放大，以免意外改变欢迎介绍页。主页改用专用的 `.mk-brand-lockup`，并把品牌名和标语拆成语义清晰的子元素：

- 中文品牌名：`枝涯 Career Arbor`
- 英文品牌名：`Career Arbor`
- 中文标语：`循枝见路，向远而生`
- 英文标语：`Follow the branches, find your path.`

视觉层级：

- 品牌名使用衬线字体与较高字重，响应式字号约 `1.55rem–2.25rem`。
- 标语使用较轻的无衬线样式，约 `0.95rem–1.1rem`。
- 品牌名与标语之间使用静态枝线或节点分隔，不使用胶囊背景。
- 品牌名必须明显大于标语，同时小于主页唯一的主 `h1`；自动测试只验证 `标语 < 品牌名 < h1`，具体视觉比例通过中英文截图复核。
- 不新增标题层级；页面继续只有一个主 `h1`。
- 容器允许换行并设置 `min-width: 0`。在 320px 窄屏下允许品牌名与标语纵向堆叠并居中。

### 4.3 P3 英文分层与边界保护

涉及组件：`frontend/src/v2/WorkbenchPage.tsx`

涉及样式：`frontend/src/v2/theme.css`

涉及翻译：`frontend/src/i18n/en.ts`

只修改展示层英文翻译，使结果表与项目既定 taxonomy 一致：

- `现在就投` → `Now Fit`
- `值得冲刺` → `Stretch Fit`
- `跳板岗位` → `Bridge Role`

内部键 `now_fit / stretch_fit / bridge_role`、API 响应和持久化值保持不变。

分层标签采用双层防护：

- 保留现有 104px 分层列作为初始设计，避免无必要地挤占岗位名列。
- 标签使用 `inline-flex`、`max-width: 100%`、`min-width: 0`、`box-sizing: border-box`、居中和稳定行高。
- 优先在英文空格处自然换行；`overflow-wrap: anywhere` 只作为未来异常长翻译的兜底。
- 标签必须完整位于所属 `td` 内，不裁剪文本，也不得与岗位名单元格相交。
- 小屏继续由既有表格容器负责横向滚动；页面根元素不得产生额外横向溢出。

## 5. 响应式与无障碍验收

目标宽度：320px、375px、650px、1280px。

品牌链接验收：

- 中文和英文均提供不小于 44px 的点击高度。
- 在实际可见的导航结构中，菜单触发器、品牌链接和语言按钮不碰撞、不越出视口。
- 键盘 `Tab` 能触发真实 `focus-visible`，焦点指示与相邻颜色的对比度至少为 3:1。
- 普通文字与背景的对比度至少为 4.5:1。
- `hover`、`focus-visible`、`active` 均有预期反馈，且不会导致布局位移。
- 模拟低动态偏好时不执行枝条伸展、位移或缩放动画。

主页锁定区验收：

- 中英文均只保留一个主 `h1`。
- 计算字号满足 `标语 < 品牌名 < h1`。
- 320px 下可换行或堆叠，页面无横向溢出。
- 保存中英文桌面和窄屏截图，用于人工确认品牌层级。

结果表验收：

- 覆盖三类中文标签和三类英文标签。
- 在 320px、375px、650px、1280px 下，标签边界完全位于所属单元格内，且不与岗位名列相交。
- 仅 `.v2-result-table-wrap` 在需要时出现横向滚动；文档根元素不横向溢出。

## 6. 测试策略

实施采用测试先行：

1. 先添加会失败的组件与翻译测试，覆盖主页品牌名/标语分离、中英文运行时切换和三层英文术语。
2. 添加少量关键 CSS 契约测试；不把具体像素和全部声明写成脆弱的正则快照。
3. 添加 Playwright 行为与几何测试，覆盖命中区域、碰撞、焦点、低动态模式、品牌层级与结果标签边界。
4. 实现最小代码使目标测试通过。
5. 运行目标测试后，再运行完整前端 `test`、`typecheck`、`build`、全量 Playwright 和 `git diff --check`。
6. 只有共享契约或后端文件发生变化才运行后端测试；本设计预期不触及后端。
